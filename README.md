# EssenciaShop Visual Prototype

Construye el prototipo visual completo de EssenciaShop, un ecommerce de dropshipping de accesorios para teléfonos y tecnología. Usa como referencia visual la opción 1 seleccionada en esta conversación: homepage premium de escritorio, minimalista y de alta conversión, inspirada en Apple Liquid Glass/glassmorphism.

Objetivo: crear una homepage responsive y funcional que convierta visitantes en compradores.

Dirección visual exacta:
- Fondo blanco/off-white con mucho espacio negativo.
- Tipografía sans moderna, elegante y muy legible.
- Negro/carbono para texto, azul eléctrico y violeta como acentos.
- Glassmorphism sutil: superficies translúcidas, blur, bordes muy suaves y sombras ligeras.
- Bordes redondeados premium.
- Hero visual de productos tecnológicos: smartphone premium, earbuds, smartwatch, power bank y cargador inalámbrico.
- Estética tecnológica premium, limpia, no recargada.
- No usar emojis como iconos; usa una librería de iconos consistente.

Estructura:
1. Barra superior con Envíos a todo el país, Pagos seguros y Soporte 24/7.
2. Header con logo textual EssenciaShop, Inicio, Tienda, Categorías, Ofertas, Novedades, búsqueda, cuenta, favoritos y carrito.
3. Hero: etiqueta “ACCESORIOS · GADGETS · TECNOLOGÍA”, headline “Tecnología que encaja contigo.”, texto de apoyo y CTA “Comprar ahora”. Añadir beneficios de envíos, pagos y garantía.
4. Categorías: Fundas y Protectores, Cargadores y Cables, Audio, Power Banks, Relojes Inteligentes, Auto, Gaming y Gadgets Inteligentes.
5. Productos destacados con cards premium, imagen grande, badges, rating, precio, precio anterior y botón “Añadir al carrito”. Usa productos demo coherentes con el nicho, sin afirmar que son proveedores reales.
6. Dos banners promocionales: “Carga sin límites” y “Fundas premium para tu teléfono”.
7. Sección “¿Por qué elegir EssenciaShop?” con productos seleccionados, envíos con seguimiento, pagos seguros y atención 24/7.
8. Testimonios con estrellas.
9. Newsletter “Suscríbete y recibe ofertas exclusivas”.
10. Footer oscuro con navegación, ayuda, contacto, redes y métodos de pago.

Interacciones:
- navegación y anchors funcionales;
- búsqueda visual funcional sobre los productos demo;
- filtros/categorías básicos;
- botones Añadir al carrito que actualicen el carrito;
- favoritos con estado activo;
- CTA del hero que lleve a productos;
- newsletter con estado de éxito;
- responsive perfecto en desktop/tablet/mobile.

Tecnología:
- React + TypeScript + Tailwind/shadcn según el stack de Lovable.
- Componentes reutilizables.
- Datos de productos separados de la UI.
- No implementar backend, auth ni pagos reales todavía; es un prototipo frontend.
- No dejar placeholders vacíos donde la referencia exige imágenes: utiliza imágenes de productos tecnológicas apropiadas y coherentes con la estética.
- Mantén el diseño enfocado en la conversión y fiel a la opción 1, evitando añadir funciones no solicitadas.
- Usa microinteracciones suaves, hover/focus states y transiciones premium.
- El resultado debe verse como una ecommerce real lista para la siguiente fase de integración.
